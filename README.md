# Risk Management Project

This project demonstrates risk identification, risk analysis,
mitigation strategies, and version control using Git.

Case study: Online Movie Ticket Booking System.

## Project scope
Customers browse movies, select seats, pay online and receive an e-ticket.
Theatre admins manage movies, shows, pricing and reports.

## Files
- `Risk_Register.csv` - the risk register (one row per risk)
- `Mitigation_Plan.md` - response strategy, mitigation, contingency, owner and review status
- `Risk_Analysis.md` - ranked risks and the top three risks

## Scoring method
Risk Score = Probability (1-5) x Impact (1-5)

| Score | Priority |
|-------|----------|
| 1-5   | Low      |
| 6-12  | Medium   |
| 13-25 | High     |

## Branches
- `main` - reviewed, stable version
- `risk-analysis` - work on additional risks and response plans
